# crypto-Live-Priceing
#### CryptoLPA is a cryptocurrency tracker web app where users can search and explore live crypto prices, market data, and trends
#### It’s designed with a clean UI, responsive layout, and real-time API data for a smooth user experience.

### Key Highlights
#### 🌍 Supports multiple currencies (USD, INR, EUR, etc.)
#### 📈 Displays live crypto prices, market cap, and volume
#### 🔍 Easy-to-use search feature
#### 📊 Responsive Website
#### ⚡ Powered by CoinGecko API

### 🛠️ Built With
#### React.js – Frontend framework
#### Vite – Fast build tool
#### CSS – Styling
#### CoinGecko API – Live crypto data

### 🔗 API Used

### This project uses the [CoinGecko](https://www.coingecko.com/) for fetching cryptocurrency data.
